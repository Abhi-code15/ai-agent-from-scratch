## 📐 Pedagogical & Architectural Guidelines
All notes in this directory strictly adhere to the standards outlined in [DESIGN.md](../DESIGN.md):
- **The Feynman Technique:** Clear explanations using everyday real-world analogies (ELI12) and zero circular jargon.
- **Visual Learning:** Architecture flowcharts (Mermaid / ASCII), comparison tables, and GitHub-style callouts (`[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`).
- **Clean Focus:** Focuses exclusively on technical topics, architectures, code anatomy, and interview concepts without external channel branding.
